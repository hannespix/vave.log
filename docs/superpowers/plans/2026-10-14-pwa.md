# PWA Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Implement in this session, then request a fresh review before merging.

**Goal:** Install the full VAVE.LOG tool as a branded app with a conservative offline fallback.
**Architecture:** Static manifest/icons plus a small allowlisted service worker; shared React PWA provider and install/settings UI. Existing Supabase flows remain online.
**Tech Stack:** Existing React, TypeScript, Vite, Node/Worker, Vitest and Playwright. No new package dependencies.
**Spec:** ../specs/2026-10-14-pwa-design.md

## Global Constraints
- EN/DE/ZH; preserve workspace/auth URLs and existing private hosting audience.
- No sensitive persistent cache, write queue, push permissions or automatic page reload.
- Root SW scope, correct MIME/CSP/no-store controls in both hosts.

## Review Focus
- A private hosting login redirect must not enter offline cache (Task 1).
- API/Auth/MCP, mutations and token-bearing URLs must bypass interception (Task 1).
- A denied/dismissed installation or worker registration error must leave normal usage intact (Task 2).
- Worker update in another tab must not discard this tab's unfinished work (Task 2).
- Offline reload, missing cache and iOS/manual installation must remain understandable in each language (Tasks 1–3).
